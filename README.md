# Практическое задание (написание работающего скрипта)
Первый проект в моем обучении.
Задача: «Анализатор текста»
Создай функцию clean_text(text), которая:

приводит текст к нижнему регистру;

удаляет все знаки препинания (. , ! ? ; : - и т.п.) — можно использовать .replace() или цикл;

разбивает строку на слова (метод .split());

возвращает список слов.

Создай функцию word_stat(words), которая принимает список слов и возвращает словарь, где ключ — слово, значение — количество его вхождений. Используй цикл и методы словаря.

Создай функцию top_words(stat, n=5), которая возвращает список из n самых частых слов (в порядке убывания частоты). Используй sorted() с ключом-лямбдой. Если слова имеют одинаковую частоту — сортируй по алфавиту (дополнительное усложнение, но можно просто по частоте).

Основная часть скрипта:

задай строку с текстом (можно взять любой английский или русский текст, например, несколько предложений);

обработай её функцией clean_text;

если список слов пуст — выведи сообщение и заверши программу (используй try/except или проверку if);

получи статистику через word_stat;

выведи на экран общее количество слов и топ‑3 самых частых слов (или топ‑5, но запроси у пользователя через input).

Добавь обработку ошибок:

если пользователь вводит не число для n — поймай ValueError и установи n=3 по умолчанию.

если текст содержит только пробелы — обработай это и не дай скрипту упасть.

Используй хотя бы один генератор списков (например, при удалении знаков препинания или при фильтрации слов).
